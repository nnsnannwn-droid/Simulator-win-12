Интерактивный веб-симулятор интерфейса Windows 12 — концепт, созданный для ознакомления и экспериментов в браузере.

## Возможности
- Рабочий стол, иконки, виджеты и часы
- Оконная система: перемещение, изменение размера, сворачивание, разворачивание и привязка окон
- Проводник с вкладками и имитацией операций с файлами
- Настройки интерфейса, темы, акцентные цвета и персонализация
- Панель быстрых настроек, уведомления и переключатели Wi-Fi/Bluetooth (демо)
- Экран блокировки и экран входа
- Встроенные приложения: калькулятор, браузер, заметки, рисование, редакторы документов/таблиц/презентаций и другие инструменты
- Анимации, эффекты и адаптация для мобильных экранов
