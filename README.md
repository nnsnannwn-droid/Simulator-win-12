# Simulator win. 12

Интерактивный веб-симулятор интерфейса Windows 12 — концепт, созданный для ознакомления и экспериментов в браузере.

## Возможности
- Рабочий стол, иконки, виджеты и часы
- Окна: перемещение, изменение размера, сворачивание/разворачивание
- Проводник с вкладками и имитацией операций с файлами
- Настройки интерфейса, темы, акцентные цвета и персонализация
- Панель быстрых настроек и уведомлений
- Экран блокировки и экран входа
- Встроенные приложения: калькулятор, браузер, заметки, рисование, редакторы документов и другие инструменты
- Анимации и адаптация для мобильных экранов

> Это браузерная демонстрация интерфейса, а не настоящая операционная система. Некоторые функции имитируются.
